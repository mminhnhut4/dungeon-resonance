# Tìm tài liệu từ root dự án

Đường dẫn dưới tương đối với root có project.godot. Khi skill cài cá nhân, tìm guide trong checkout dự án, không tìm cạnh thư mục skill.

| Công việc | Tài liệu và source entry |
|---|---|
| Nhận nguồn/tiến độ | docs/team/START_HERE.md, TEAM_PLAN.md, BACKLOG.md; PROJECT_STATE/DECISIONS |
| Map | docs/team/MAP_GUIDE.md; scripts/world/exterior_route_catalog.gd, exterior_room.gd; scripts/rooms/dungeon_room.gd |
| Bùa | docs/team/SPELL_GUIDE.md; resonance_controller/resolver, spell_snapshot/context/executor; inventory/session |
| Nhân vật | docs/team/CHARACTER_GUIDE.md; Player motor/FSM, BaseEnemy/WorldEnemyData, BossGolem/UV rig, NPC owners |
| QA/merge | docs/team/QA_AND_HANDOFF.md, CONTRIBUTING.md; tests/run_tests.ps1 |
| Prompt/skill | docs/team/AI_SKILL_GUIDE.md |
| Bằng chứng combat | docs/COMBAT_VISUAL_FIX_20261007.md; docs/team/evidence/README.md |

Guide cùng repo là nguồn chi tiết duy nhất. Roadmap cũ cần đối chiếu state/code; thiết kế không đồng nghĩa runtime đã có.
