# Props hầm ngục

Thư mục cho texture prop đã tách: cột, đuốc, rương, cổng và đồ trang trí.

Sheet concept hiện được giữ đầy đủ ở `../tilesets/dungeon_stone_tileset.png`; chưa tách prop khỏi ảnh. Không coi bố cục sheet này là grid TileSet hoàn chỉnh. Asset trình diễn cũ trong `assets/presentation` tiếp tục dùng như hiện hành.
