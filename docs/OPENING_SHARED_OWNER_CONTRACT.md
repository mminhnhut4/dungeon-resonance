## Shared event API

`commit_extension_event(scope_id, event_id, materials_cost, souls_cost, next_state, expected_revision=0, fence={}, guard=Callable()) -> Dictionary`

Result has `ok`, `status` (`committed`, `already_committed`, `rejected`, `quarantined`, `extension_quarantined`) and optional `error`/`revision`. Scope state, its receipt and bank costs commit together. Same receipt + same arguments is replay success; different arguments conflict. Expected revision is checked after replay detection. No refund/new event ID on ambiguous commit: reload/recover before an explicit retry. Receipts are bounded to 256 per scope; 8 scopes maximum, no silent pruning. `extension_state(scope_id)` is detached; an unsupported scope returns `{}` and `extension_revision(scope_id)` returns **-1**, never a new zero sequence. JSON data only: no executable resources/objects/callables in saved content.

Storage is exactly one root `event_extensions = {schema_version:1, namespaces:{scope_id:{revision,state,receipts}}}`. Other scopes survive each write. Avoid storing a second root copy of any scope outcome.

After loading/migrating the core profile, trusted composition calls `migrate_legacy_event_scope("npc_social","npc_social_progress",NpcSocialProgress.valid)` and `migrate_legacy_event_scope("courier","courier_opportunity",SanctuaryProfile._valid_courier)`. Valid data moves into the canonical scope and its old root field is removed in **one commit**. Replay is `already_migrated`; equal preexisting scope removes only the legacy mirror, conflicting data returns `extension_quarantined`. Malformed/future legacy data is preserved and disables only its subsystem action. The core writer neither discards it nor sets global read_only for that failure. Namespace state stays JSON-opaque to the generic codec; a subsystem validates its own state before quoting/acting. Invalid global journal/seal/format protocol remains a whole-profile quarantine because authority cannot be proved.

Before social migration, the owner extracts the durable legacy and any existing namespace raw spans and calls `JsonSpans.unique_value` on each. Duplicate inner keys, missing required spans, invalid extraction or a changed RAM/parsed image return `extension_quarantined` before deletion or debit. This prevents a last valid duplicate `event_id` from erasing ambiguous original evidence. Unrelated HP/bank saves continue to preserve those exact spans. The same checks apply when an equal-looking namespace already exists.
